# 🐍 Project 1: Snake, Water, Gun Game

## 📌 Description

Snake, Water, Gun is a simple Python-based command-line game.

In this project, the user plays the game against the computer. The computer randomly selects one option, and the user enters their choice.

## 🎮 Game Rules

- 🐍 Snake beats 💧 Water
- 💧 Water beats 🔫 Gun
- 🔫 Gun beats 🐍 Snake
- If both choose the same option, it is a **Draw**.

## 🛠️ Concepts Used

- Python
- Variables
- Input and Output
- Conditional Statements
- `if-elif-else`
- Random Module
- User Input
